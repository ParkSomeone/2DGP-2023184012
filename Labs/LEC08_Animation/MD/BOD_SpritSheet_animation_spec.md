# BOD 스프라이트시트 애니메이션 명세

## 대상 이미지

- 이미지 파일: `BOD_SpritSheet.png`
- 사용 모듈: `pico2d`
- 이미지 위치: `LEC08_Animation/BOD_SpritSheet.png`

## 목표

`pico2d`를 사용해 스프라이트시트에 포함된 여러 애니메이션을 출력한다.
현재 단계에서는 실행 코드가 아니라 구현에 필요한 규칙과 데이터를 정의한다.

## 스프라이트시트 데이터 규칙

각 애니메이션은 하나의 행 또는 지정된 영역으로 관리한다. 애니메이션마다 프레임 수가 다를 수 있으며, 각 프레임의 가로 폭도 일정하지 않을 수 있다.

따라서 프레임을 고정 폭으로 나누지 않고, 각 애니메이션의 열별 폭 정보를 별도로 저장해야 한다.

| 애니메이션 | 행 또는 영역 | 프레임별 가로 폭 | 프레임 수 | 세로 위치 | 프레임 높이 |
|---|---|---|---:|---:|---:|
| 애니메이션 1 | 확인 필요 | `[폭1, 폭2, ...]` | 확인 필요 | 확인 필요 | 확인 필요 |
| 애니메이션 2 | 확인 필요 | `[폭1, 폭2, ...]` | 확인 필요 | 확인 필요 | 확인 필요 |

### 프레임 데이터에 포함할 정보

- 프레임의 시작 x 좌표
- 프레임의 시작 y 좌표
- 프레임의 가로 폭
- 프레임의 세로 높이
- 애니메이션별 전체 프레임 수

각 열의 폭이 다르므로 다음 프레임의 x 좌표는 이전 프레임의 x 좌표와 이전 프레임의 폭을 기준으로 계산한다.

## 출력 크기

애니메이션은 윈도우 안에 들어오도록 출력 크기를 자동으로 계산한다.

- 원본 스프라이트의 가로세로 비율을 유지한다.
- 윈도우의 가로 폭과 세로 높이를 모두 넘지 않도록 한다.
- 가로 기준 크기와 세로 기준 크기 중 더 작은 배율을 사용한다.
- 프레임마다 원본 크기가 달라도 같은 애니메이션의 출력 기준을 유지해 화면에서 크기가 갑자기 변하지 않도록 한다.

## 출력 위치

스케일링한 애니메이션의 중심 좌표를 윈도우의 정중앙에 둔다.

- 화면 중심 x 좌표: 윈도우 가로 크기의 절반
- 화면 중심 y 좌표: 윈도우 세로 크기의 절반
- `pico2d`의 중심 기준 그리기 방식을 사용한다.

## 재생 규칙

각 애니메이션은 다음 순서로 재생한다.

1. 애니메이션의 모든 프레임을 순서대로 출력한다.
2. 위 과정을 5회 반복한다.
3. 5회 반복이 끝나면 1초 동안 정지한다.
4. 정지가 끝나면 같은 애니메이션을 다시 5회 반복한다.
5. 이 과정을 무한히 반복한다.

애니메이션마다 프레임 수가 다르므로 반복 횟수는 프레임 수가 아니라 애니메이션 재생 완료 횟수를 기준으로 센다.

## 구현 전 확인 사항

- `BOD_SpritSheet.png`의 애니메이션 행 또는 영역 구분
- 각 애니메이션의 프레임 수
- 각 열의 실제 가로 폭
- 각 프레임의 세로 위치와 높이
- 윈도우의 기본 가로세로 크기
- 애니메이션 전환 순서

이 문서는 위 정보가 확인된 뒤 실행 코드로 옮기기 위한 사전 명세다.
