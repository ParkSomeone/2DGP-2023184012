# update() 구현 단계

## 현재 역할

`update()`는 현재 프레임, 애니메이션 반복 횟수, 정지 시간을 갱신하는 함수다.
현재 1~7단계 구현이 완료되었으며, 단계별 동작 확인용 `print()`가 남아 있다.

## 개발 단계 상태

| 단계 | 구현 내용 | 상태 |
|---|---|---|
| 1단계 | 현재 시간 읽기 | 완료 |
| 2단계 | 프레임 변경 간격 검사 | 완료 |
| 3단계 | 현재 프레임 번호 변경 | 완료 |
| 4단계 | 마지막 프레임에서 첫 프레임으로 순환 | 완료 |
| 5단계 | 현재 애니메이션 목록에서 프레임 수 계산 | 완료 |
| 6단계 | 5회 재생 후 정지 상태 전환 | 완료 |
| 7단계 | 1초 후 프레임과 반복 횟수 초기화 | 완료 |

## 작동 단계

1. 프레임이 바뀐 뒤 경과 시간을 계산한다.
2. 프레임 변경 시간이 되었는지 확인한다.
3. 현재 프레임 번호를 다음 프레임으로 변경한다.
4. 마지막 프레임 다음에는 첫 프레임으로 순환한다.
5. 마지막 프레임을 재생하면 애니메이션 반복 횟수를 증가시킨다.
6. 5회 재생하면 프레임 변경을 멈추고 1초를 기다린다.
7. 1초가 지나면 반복 횟수와 프레임을 초기화한다.

## 단계별 구현

### 1단계: 시간 기준 준비

- `get_time()`으로 현재 시간을 읽는다.
- 구현 확인용 출력은 최종 정리 단계에서 제거한다.

### 2단계: 프레임 변경 간격 검사

- `frame_interval`과 마지막 프레임 시간을 비교한다.
- 충분한 시간이 지난 경우에만 프레임 갱신을 진행한다.

### 3단계: 현재 프레임 변경

- 변경 시간이 되면 `frame`을 1 증가시킨다.

### 4단계: 마지막 프레임 처리

- 프레임 수에 도달하면 `frame`을 0으로 되돌린다.
- `animation_repeat`를 1 증가시킨다.

### 5단계: 애니메이션별 프레임 수 적용

- `len(animations[current_animation])`으로 현재 애니메이션의 프레임 수를 계산한다.
- 현재 목록은 검증용 임시 프레임 데이터이며, 이후 실제 스프라이트 데이터로 교체한다.

### 6단계: 5회 반복 후 정지

- `animation_repeat`가 5가 되면 `is_paused`를 `True`로 변경한다.
- `pause_start_time`에 정지 시작 시간을 저장한다.

### 7단계: 1초 후 재생 재개

- 정지 시간이 1초 이상이면 `is_paused`를 해제한다.
- `animation_repeat`와 `frame`을 0으로 초기화한다.

## 단계별 구현 확인 코드

각 단계의 구현 직후 다음과 같은 임시 출력문을 넣어 실행 여부를 확인한다.

1. 시간 기준 준비: `print('[update] stage 1: time prepared')`
2. 프레임 변경 간격 검사: `print('[update] stage 2: frame interval checked')`
3. 현재 프레임 변경: `print('[update] stage 3: frame changed')`
4. 마지막 프레임 처리: `print('[update] stage 4: animation cycle completed')`
5. 애니메이션별 프레임 수 적용: `print('[update] stage 5: frame count applied')`
6. 5회 반복 후 정지: `print('[update] stage 6: five repetitions checked')`
7. 1초 후 재생 재개: `print('[update] stage 7: playback resumed')`

7단계까지 정상 동작을 확인하고 나면 위의 모든 확인용 `print()`문을 삭제한다. 최종 코드에는 프레임과 재생 상태 갱신 기능만 남겨야 한다.

## 구현 검증 결과

가상 시간을 사용해 `update()`만 분리 실행하여 다음 동작을 확인했다.

- 8프레임 애니메이션이 5회 재생되면 정지한다.
- 정지 중에는 프레임이 유지된다.
- 1초가 지난 뒤 다음 프레임 검사에서 재생을 재개한다.
- 재개 시 `frame`과 `animation_repeat`가 0으로 초기화된다.
