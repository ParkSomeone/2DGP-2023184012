# render() 구현 단계

## 현재 역할

`render()`는 현재 프레임을 스프라이트시트에서 잘라 화면 중앙에 출력하는 함수다.
현재는 함수 호출 확인용 `print()`만 수행한다.

## 작동 단계

1. 화면을 지운다.
2. 현재 애니메이션과 프레임의 영역 정보를 가져온다.
3. 원본 프레임의 폭과 높이를 확인한다.
4. 윈도우에 맞는 비율 유지 배율을 계산한다.
5. 윈도우의 정중앙 좌표를 계산한다.
6. 현재 프레임을 계산된 크기로 중앙에 출력한다.
7. 화면을 갱신한다.

## 단계별 구현

### 1단계: 화면 초기화

- 테스트용 `print()`를 화면을 지우는 코드로 교체한다.

### 2단계: 현재 프레임 정보 가져오기

- 현재 애니메이션과 프레임의 시작 x, y, 폭, 높이를 가져온다.

### 3단계: 원본 비율 계산

- 현재 프레임의 원본 가로세로 비율을 계산한다.

### 4단계: 출력 배율 계산

- 윈도우의 가로 기준 배율과 세로 기준 배율을 계산하고 더 작은 값을 선택한다.

### 5단계: 출력 크기 결정

- 선택한 배율을 원본 프레임 폭과 높이에 적용해 출력 크기를 계산한다.

### 6단계: 화면 중앙 출력

- 윈도우의 가로와 세로 절반을 중심 좌표로 사용해 현재 프레임을 출력한다.

### 7단계: 화면 갱신

- 스프라이트 출력 후 화면을 갱신하고, 프레임 폭이 달라도 중심이 유지되는지 확인한다.

## 단계별 구현 확인 코드

각 단계의 구현 직후 다음과 같은 임시 출력문을 넣어 실행 여부를 확인한다.

1. 화면 초기화: `print('[render] stage 1: canvas cleared')`
2. 현재 프레임 정보 가져오기: `print('[render] stage 2: frame data loaded')`
3. 원본 비율 계산: `print('[render] stage 3: aspect ratio calculated')`
4. 출력 배율 계산: `print('[render] stage 4: scale calculated')`
5. 출력 크기 결정: `print('[render] stage 5: draw size calculated')`
6. 화면 중앙 출력: `print('[render] stage 6: centered frame drawn')`
7. 화면 갱신: `print('[render] stage 7: canvas updated')`

7단계까지 정상 동작을 확인하고 나면 위의 모든 확인용 `print()`문을 삭제한다. 최종 코드에는 화면 출력과 갱신 기능만 남겨야 한다.

## 완료 기준

- 현재 프레임만 출력된다.
- 스프라이트가 윈도우 정중앙에 있다.
- 원본 비율이 유지된다.
- 프레임마다 폭이 달라도 위치가 흔들리지 않는다.
